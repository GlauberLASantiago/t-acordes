SOBRE ESTA EDIÇÃO

Um laboratório para ouvir e aprender.

O T-Acordes é um aplicativo educativo de formação de acordes. Escolha uma fundamental, combine terça, quinta e sétima, visualize as notas na pauta e ouça o resultado.

Esta recriação web recupera os conteúdos e as combinações de acordes do aplicativo Android original. A interface foi adaptada para computadores e celulares, e a reprodução dos acordes utiliza síntese de áudio no navegador.

Privacidade e uso

Os acordes salvos e suas preferências ficam apenas no armazenamento local deste navegador. Não é necessário criar uma conta. O áudio começa depois de uma interação com os controles.
